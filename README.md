# raphaelssampaio.github.io — Portfolio

Personal portfolio of Raphael Sampaio, Senior React Native Engineer.

**Live:** https://raphaelssampaio.github.io

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- GitHub Pages

## Sections

- Hero
- About
- Projects
- Skills
- Experience
- Contact

## Run locally

```bash
npm install && npm run dev
```

## Build

```bash
npm run build
```

Generates a static export in `/out`.

## Deployment

GitHub Actions deploys automatically to GitHub Pages on every push to `main` (see `.github/workflows/deploy.yml`).
